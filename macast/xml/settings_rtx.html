使用说明

  1. 保持手机和电脑处于同一局域网，并允许程序通过 Windows 专用网络防火墙。
  2. 启动后在系统托盘找到 Macast RTX Edition。
  3. 在任意兼容的 DLNA 控制端点击投放，选择名称中带有 Macast RTX 的设备。
  4. 程序会检测显卡并设置 RTX 功能的默认状态，也可通过托盘菜单分别关闭 VSR 和 HDR。
  5. 在 NVIDIA App 的“系统 → 视频”中确认增强状态是否处于活动。
  6. 需要更多播放器支持时，在设置页“插件”标签里安装 Renderer 或 Protocol 插件（清单来自本仓库的 plugins 目录），Macast 会自动重启，随后在托盘菜单中启用。
HDR 前置条件

需要 RTX 显卡、支持 HDR 的显示器、较新的 NVIDIA 驱动，并在 Windows“设置 → 系统 → 显示 → HDR”中打开 HDR。
