# Macast RTX Edition 中文说明

项目使用 [README.md](README.md) 作为主要中文说明，包含功能、平台支持、安装与常见问题。

本项目从 [ccjjxx99/Macast-RTX-Edition](https://github.com/ccjjxx99/Macast-RTX-Edition) 克隆并继续开发。感谢 ccjjxx99、[xfangfang/Macast](https://github.com/xfangfang/Macast) 及所有贡献者。

按操作系统准备环境和构建程序，请查看 [中文构建指南](docs/Build_ZH.md) 或 [英文开发文档](docs/Development.md)。Windows 提供自动化 EXE 构建；macOS 推荐源码安装；Linux 可从源码运行或生成单文件可执行程序。RTX Video VSR/HDR 仅在 Windows 上提供。
